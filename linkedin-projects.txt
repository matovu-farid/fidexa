PROJECT 1 — Rishi (AI-Powered Book Reader)
--------------------------------------------------------------------------------

PROJECT NAME:
Rishi — AI-Powered Book Reader

DESCRIPTION:
Rishi is an AI-powered reading companion that turns any book into an interactive learning experience. It lets readers import EPUBs from their library or by URL, then chat with an AI agent that has full context of the text — asking questions, getting explanations, exploring themes, and generating summaries on demand.

I designed and built Rishi end-to-end as a cross-platform product: a Next.js web app, an Electron desktop client (Mac/Windows/Linux), and an Expo / React Native mobile app, all sharing a single TypeScript codebase via a pnpm monorepo with a shared package layer.

Key engineering work:
• Architected a pnpm + Turborepo monorepo with shared business logic, types, and DB schema consumed by web, desktop, and mobile clients.
• Built an AI agent using the OpenAI Agents SDK with retrieval over book content, so the model answers grounded in the actual text the reader is viewing.
• Implemented EPUB parsing, pagination, and a synchronized reader UI using epubjs across Electron and React Native.
• Set up auth with Clerk, storage with Drizzle ORM, and Sentry-based error tracking across all three clients.
• Built Electron packaging and signing for Mac (x64 + arm64), Windows, and Linux, with Playwright E2E tests for the desktop app.
• Implemented offline-first behavior on mobile using expo-sqlite and secure store for credentials and library state.

Rishi is the flagship product of my studio, Fidexa.

PROJECT 2 — Maria (Crypto Trading Bot)
--------------------------------------------------------------------------------

PROJECT NAME:
Maria — Automated Crypto Trading Bot (Effect-TS)

DESCRIPTION:
Maria is a production cryptocurrency trading bot that runs automated strategies on Binance Futures. It's built in TypeScript with Effect-TS, giving the entire trading pipeline — market data ingestion, signal generation, order routing, position tracking, and reconciliation — typed errors, structured concurrency, and dependency injection from the ground up.

Highlights:
• Pluggable strategy interface: new strategies are added as standalone modules with their own configuration, logging namespace, and tests.
• Real-time market data analysis combining technical indicators, sentiment signals, and risk-aware position sizing.
• Automated order lifecycle — submission, partial fill handling, stop-loss / take-profit management, and reconciliation against exchange state on startup so the bot recovers cleanly from crashes.
• Type-safe configuration and secrets management via Effect's Layer / Context model — no hidden globals.
• Containerized with Docker Compose for both dev and production, with structured per-strategy logging and log rotation.
• Comprehensive Vitest unit and integration tests; runs 24/7 against a live exchange.

The result is a trading system I can extend and operate with confidence — adding a new strategy or risk rule is a typed, isolated change rather than a refactor.

PROJECT 5 — Facet (AI Knowledge-Base Chat)
--------------------------------------------------------------------------------

PROJECT NAME:
Facet — AI Chat with Retrieval, Tool Use & Parallel Execution

DESCRIPTION:
Facet is a T3-stack web app that combines authenticated workspaces with an AI chat that retrieves context from a Pinecone vector store and calls tools against the app's own database. It was an experiment in making AI assistants feel responsive and trustworthy by exposing what they're actually doing in real time.

What's interesting about the build:
• Retrieval-augmented chat powered by LlamaIndex with Pinecone as the vector store — sources are surfaced inline with relevance scores so users can verify answers.
• Tool calling against the app's own data (e.g., `getOrganizationById`), with named badges in the UI showing which tools fire on each turn.
• Parallel tool execution — when the model requests multiple tools, they run concurrently rather than sequentially, cutting response latency 40–60% on complex requests.
• Granular status surface: "context retrieved", "thinking", "tool running", "tool success/error", "generating", "complete" — each with its own badge color and animation.
• T3 Stack foundation: Next.js App Router, NextAuth.js (Prisma adapter), Prisma + PostgreSQL, shadcn/ui, TanStack Query, and React Hook Form + Zod.
• Tested with Vitest and Cypress; emails via Resend.

Facet became my reference implementation for "AI features that show their work" — a pattern I now reuse in client projects.

Next.js • LlamaIndex • Pinecone • AI Engineering • TypeScript
