# Fidexa Logo System

## Approved direction

The selected direction is **Folded F**: a compact geometric monogram built from an ink-colored F with violet and mint folded planes. It keeps the structural language of Fidexa’s existing cube mark while making the F and the silhouette more immediately recognizable.

## Deliverables

- Editable Pencil source: `fidexa-logo.fig`, page `Fidexa Logo`.
- Logo system board: `public/fidexa-logo-system.svg`.
- Primary lowercase lockup: `public/fidexa-primary-lockup.svg`.
- Standalone app-icon mark: `public/fidexa-app-icon.svg`.

## Visual system

- Ink: `#101828`
- Violet: `#7C5CFC`
- Mint: `#37D6C0`
- Cloud: `#F7F9FC`
- Wordmark: lowercase `fidexa`, Inter Bold.
- Optional descriptor: `SOFTWARE STUDIO`, Inter Regular.

The primary lockup is intended for light backgrounds. The logo system board also includes a reversed lockup for dark surfaces and a standalone mark for favicon, app-icon, and avatar contexts.
