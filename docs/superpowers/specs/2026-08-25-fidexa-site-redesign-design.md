# Fidexa Studio System — Site Redesign

## Direction

The redesign uses **Fidexa Studio System**: a dark, editorial, modular interface that treats client solutions and internal products as two engines of one studio. The existing site’s core story is preserved, but the presentation becomes more visual, more navigable, and more useful as a portfolio and conversion tool.

## Pencil document

The editable source is `fidexa-logo.fig`. New pages:

- `Design System` — tokens, colors, typography, components, and principles.
- `Home` — hero, dual-studio proposition, selected work, and conversion paths.
- `Work Index` — project grid and category filter model.
- `Case Study — Rishi` — reusable product case-study template.
- `Studio` — client solutions, innovation lab, process, and capabilities.
- `Contact` — project brief form with response expectation and AI alternative.

## Visual system

- Ink: `#101828`
- Cloud: `#F7F9FC`
- Violet: `#7C5CFC`
- Mint: `#37D6C0`
- Muted ink: `#667085`
- Dark muted: `#AAB4C5`
- Typeface: Inter, with bold display headlines and compact uppercase labels.
- Folded F: recurring navigation anchor and geometric motif.

## Content model

The redesign expands the current single landing page into a clear journey: understand the studio on Home, browse Work, inspect a reusable Case Study, learn how Fidexa operates on Studio, and start a project through Contact. Rishi is the first detailed case-study example; the Work Index continues to use the existing portfolio themes including finance, AI, property, developer tools, and travel.
