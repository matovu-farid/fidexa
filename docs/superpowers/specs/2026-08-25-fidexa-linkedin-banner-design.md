# Fidexa LinkedIn Page Banner

## Direction

Create a 4200×700 LinkedIn Page cover using the approved Folded F identity. The banner uses a dark Ink-to-navy field, restrained grid and orbital geometry, and a low-contrast oversized Folded F silhouette in the right half. The primary lockup stays in the left-center safe area, away from the profile-card overlap and the lower-right crop risk.

## Copy

- Eyebrow: `FIDEXA / SOFTWARE STUDIO`
- Headline: `Product engineering studio`
- Supporting line: `Shipping web, Apple, and AI products.`

## Deliverables

- Editable vector source: `public/fidexa-linkedin-banner.svg`
- LinkedIn upload asset: `public/fidexa-linkedin-banner.png`

The PNG uses LinkedIn’s current recommended Page cover dimensions and stays below the platform’s 3 MB maximum.
